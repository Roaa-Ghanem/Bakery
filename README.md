# Sweet Bakery Website

A beautiful and interactive bakery website landing page with elegant animations and responsive design.

## Features

- Responsive layout that works on mobile, tablet, and desktop devices
- Beautiful animations and interactive elements
- Parallax effects and hover interactions
- Mobile-friendly navigation
- Cart functionality
- Newsletter subscription form
- Wave animations for section dividers
- Product showcases with hover effects

## Technologies Used

- HTML5
- CSS3 (with custom variables and animations)
- JavaScript (vanilla, no frameworks)
- Font Awesome for icons
- Google Fonts (Playfair Display and Poppins)
- Unsplash for high-quality food images

## Project Structure

- `index.html` - Main HTML structure
- `style.css` - All styling and animations
- `script.js` - Interactive functionality and animations

## How to Use

1. Clone this repository
2. Open `index.html` in a web browser
3. Enjoy the interactive bakery website!
